# Electric Vehicle Market Performance & Insights

## Project Overview
This project analyzes an Electric Vehicle (EV) market dataset to identify patterns and insights related to manufacturers, vehicle categories, regional market performance, pricing, driving range, and model years.

## Objectives
- Analyze electric vehicle market data.
- Explore manufacturer and vehicle-category trends.
- Compare vehicle prices and driving ranges.
- Examine regional values and annual sales figures recorded in the dataset.
- Create interactive visualizations and dashboards.
- Present insights through a Tableau dashboard and story.

## Tools & Technologies
- **Tableau Desktop** — Data visualization and interactive dashboards
- **SQL** — Data storage, querying, and analysis
- **Python** — Data loading and preparation
- **SQLite** — Database storage
- **Flask** — Web integration
- **GitHub** — Project version control and documentation

## Key Features
- Data preparation and quality checks
- SQL queries for data analysis
- Interactive Tableau worksheets and dashboard
- Filters for manufacturer, region, category, and model year
- Tableau story with multiple scenes
- Responsive Flask web interface for embedding published Tableau content

## Dataset
The project uses `ev_market_train.csv`, containing electric vehicle market records and attributes such as manufacturer, model name, model year, market region, vehicle category, price, driving range, battery capacity, annual sales units, and customer ratings.

## Project Workflow
1. Understand the problem.
2. Collect and inspect the dataset.
3. Store the data in a database.
4. Perform SQL queries.
5. Prepare data for visualization.
6. Build Tableau worksheets and dashboards.
7. Create a Tableau story and interactive filters.
8. Integrate published Tableau content into a Flask website.
9. Test the application and document the results.

## Project Status
In progress — database integration, Tableau visualizations, dashboard, story, and web deployment will be completed and verified as part of the project.

## How to Run the Flask Website
1. Install Python.
2. Install dependencies using `pip install -r requirements.txt`.
3. Configure the Tableau dashboard and story URLs as environment variables.
4. Run `python app.py`.
5. Open the local URL shown in the terminal.
